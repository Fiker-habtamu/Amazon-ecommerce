# Full-Stack E-Commerce Platform (Amazon Clone)

A complete, responsive 7-page e-commerce application featuring real-time database management, secure user authentication, and live payment processing.

## 🚀 Features
* **7 Core Pages:** Landing, Dynamic Categories, Item Details, Cart, Auth, Stripe Checkout, and Live Order History.
* **Authentication:** Secure signup/login powered by Firebase Auth.
* **Protected Routes:** Restricts access to Payment and Orders pages unless authenticated.
* **Payment Integration:** Fully functional credit card processing via Stripe API.
* **Database (Firestore):** Real-time data synchronization utilizing the modern Firebase v9+ Modular SDK to store individual user order histories securely.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, React Router, Material UI (Stars/Icons), CSS3 (BEM methodology)
* **Backend:** Node.js, Express
* **Services:** Firebase Auth & Firestore, Stripe API
